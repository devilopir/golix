Room token

A script needs this token the first time it opens a room: pass it as token in HBInit, next to your roomSecret. It works once, for ten minutes. A room that comes back with the same roomSecret needs no new token.

Script'in bir odayı ilk kez açarken bu token'a ihtiyacı var: HBInit'e roomSecret'ın yanında token olarak ver. Bir kez ve on dakika geçerli. Aynı roomSecret ile yeniden açılan oda yeni token istemez.
