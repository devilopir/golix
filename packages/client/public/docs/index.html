Golix for developers

Host Golix rooms from Node with golix.js, script what happens in them, join rooms as a bot and write your own stadiums.

Getting started

golix.js needs Node 22 or later.

npm install golix.js

A room registers with the public lobby, and players connect straight to your process over WebRTC, or through the lobby when a direct connection fails.

const golix = require('golix.js');

golix().then((HBInit) => {
  const room = HBInit({
    roomName: 'My room',
    maxPlayers: 12,
    noPlayer: true,
    lobby: 'wss://golix.cosmosfutsal.com',
    // 22 characters of A-Z, a-z, 0-9, - and _: keeps the room link across restarts.
    roomSecret: process.env.ROOM_SECRET,
    // Only the first time this roomSecret opens a room: from https://golix.cosmosfutsal.com/headlesstoken
    token: process.env.ROOM_TOKEN,
  });
  room.onRoomLink = (link) => console.log(link);
  room.onPlayerJoin = (player) => room.sendAnnouncement(`Welcome ${player.name}`, player.id);
});

With ES modules: import golix from 'golix.js'; const HBInit = await golix();

Callbacks run inside the room's tick, 60 times a second. Methods called from them take effect on the next tick, and an exception thrown by a callback is logged without stopping the room.

Customizing the game

Physics for one player

room.setPlayerPhysics(player.id, { kickStrength: 7, acceleration: 0.12, radius: 17 });
room.getPlayerPhysics(player.id); // { kickStrength: 7, acceleration: 0.12, radius: 17 }
room.setPlayerPhysics(player.id, null); // back to the stadium's

Any of radius bCoef invMass damping acceleration kickingAcceleration kickingDamping kickStrength kickback; the fields you leave out keep the stadium's playerPhysics. The change lasts across kickoffs until you clear it.

Text on the game screen

room.setHudItem('score', { text: 'Round 2 of 3', x: 0.5, y: 0.12, align: 'center', color: 0xffd34d, size: 22 });
room.clearHudItem('score');

x and y place the item as a fraction of the screen from the top left. Calling setHudItem with the same id replaces the item. Up to 16 items of 100 characters, sizes 8 to 64. Players who join later see them too.

Camera

room.setCamera({ playerId: scorer.id }, 1.6); // follow a player, zoomed in
room.setCamera({ discIndex: 0 });              // the ball
room.setCamera({ x: 0, y: 0 }, 0.8);           // a fixed point
room.setCamera(null);                          // back to normal

The zoom, 0.25 to 4, multiplies each player's own view setting.

Kits

setPlayerColors(id, angle, textColor, colors) dresses one player in their own kit instead of the team's, with up to five stripes; clearPlayerColors(id) takes it off.

Joints

// A rope from the ball to a player that snaps past 150 units
room.addJoint({ d0: { discIndex: 0 }, d1: { playerId: player.id }, length: [0, 120], strength: 0.05, breakLength: 150 });
room.onJointBreak = (index) => room.sendAnnouncement('The rope snapped');

An end is a stadium disc, { discIndex } below the stadium's disc count, or a player, { playerId }; a player's joint rests while they are off the field. length defaults to the distance when the joint is added, a number fixes it and [min, max] allows a range. strength is 'rigid' (the default) or a spring coefficient, color a number or 'transparent' (the default), and breakLength the distance at which it breaks; without one it never does. Joints last until the game ends. The list starts with the stadium's own joints, so removeJoint removes those too.

Action keys

setActionKeys(true) lets players send six extra keys, Q, E, R, F, C and V by default. Each press and release arrives as onPlayerAction(player, actionId, isPressed); the keys do nothing by themselves.

Room hosts who play in the browser get most of this without code, from the Mods button in their room.

Flags

room.InputFlags      // up 1, down 2, left 4, right 8, kick 16
room.CollisionFlags  // ball 1, red 2, blue 4, redKO 8, blueKO 16, wall 32, all 63,
                     // kick 64, score 128, c0 1<<28, c1 1<<29, c2 1<<30, c3 1<<31

With action keys on, player.input also carries them as bits 32, 64, 128, 256, 512 and 1024 for actions 1 to 6.

Joining as a player

const { session, auth, key } = await golix.joinRoom({
  room: 'https://golix.cosmosfutsal.com/play?c=<id>',
  name: 'bot',
});
session.send({ type: 'chat', text: 'hi' });
session.onEvent((event) => console.log(event));

Store key and pass it back as key to join again with the same auth. A refused join rejects with a golix.JoinError whose reason is password, full, banned, invalid, rateLimited, captcha, connLimit, version (the room runs another Golix version) or closed. Joining again with a key that is already in the room replaces the older connection.

Replays

golix.decodeReplay(bytes), golix.encodeReplay(replay) and golix.trimReplay(replay, fromFrame, toFrame) read, write and cut .glx replays. The game runs at 60 frames per second, so a 10 second clip ending at frame f is trimReplay(replay, f - 600, f). Replays open in the game from the room list, where every match you play is also saved; the last 50 stay in the browser. A link like /replay?url=<https address of the file>&t=90 opens a replay 90 seconds in.

Stadium files

A stadium is a JSON5 text file (.hbs) holding one object. Every field but name, width and height has a default; null counts as leaving a field out.

FieldMeaning
nameShown in the room.
width, heightHalf-size of the area the camera stays in.
maxViewWidthZooms in when a screen would show more than this width; 0 (default) for no limit.
cameraFollow"ball" (default) follows the ball and the player, "player" only the player.
spawnDistanceHow far from the centre teams line up at kickoff when there are no spawn points. Default 200.
redSpawnPoints, blueSpawnPoints[[x, y], ...] kickoff positions, taken in player order; a player who joins a team mid-game takes the last one.
kickOffReset"partial" (default) resets the ball and the players at kickoff, "full" every disc.
canBeStoredWhether players may keep the stadium. Default true.
bg{ type, width, height, kickOffRadius, cornerRadius, goalLine, color }; type is "grass", "hockey" or "none" (default), color default "718C5A".
traitsNamed sets of default fields; an object with "trait": "name" takes the fields it leaves out from that set.
vertexes{ x, y, bCoef, cMask, cGroup }: points that discs bounce off.
segments{ v0, v1, curve, curveF, bias, bCoef, cMask, cGroup, vis, color }: lines between two vertexes. curve bends it by that many degrees; bias makes it one-sided and that thick.
planes{ normal: [x, y], dist, bCoef, cMask, cGroup }: endless walls, usually the outer bounds.
goals{ p0: [x, y], p1: [x, y], team }: a line that scores for the other team when a score disc crosses it.
discs{ pos, speed, gravity, radius, invMass, damping, bCoef, color, cMask, cGroup }: posts, extra balls and anything else round. invMass: 0 does not move.
joints{ d0, d1, length, strength, color, breakLength }: links two discs. length null keeps their starting distance, a number fixes it, [min, max] allows a range; strength "rigid" (default) or a number for a spring; breakLength breaks the joint once its discs are farther apart than that.
playerPhysics{ radius, bCoef, invMass, damping, acceleration, kickingAcceleration, kickingDamping, kickStrength, kickback, gravity, cGroup }.
ballPhysicsA disc for the ball, which always scores and can be kicked, or "disc0" to use the first disc as the ball.
  • Colors are "RRGGBB", [r, g, b] or "transparent". A transparent disc still shows its outline; a transparent segment is drawn white unless vis is false.
  • Collision flags are lists of names: ["ball", "red", "c0"]. Two objects collide when each one's cGroup shares a flag with the other's cMask.
  • Defaults: vertexes, segments and planes have bCoef 1, cGroup wall and cMask all; discs radius 10, invMass 1, damping 0.99, bCoef 0.5, color white, cGroup and cMask all.
  • Limits: 4096 vertexes, segments, planes, goals and joints each, 255 discs counting the ball, and one million characters per file. A field of the wrong type, like a number written as text, fails the file.
  • The ball and stadium discs are drawn over the players.

Room protection

Every room gets these without any code:

  • One address can hold 30 connections to the lobby and open 30 within 10 seconds.
  • One address gets 5 join attempts a minute per room.
  • A connection that sends more than 300 messages a second is disconnected and kept out for a minute.
  • Chat is rate limited per player.
  • Raid guard. When 6 players with new keys join within 10 seconds, the room asks every new joiner for a captcha for 5 minutes and announces it. The first 2 minutes of a room and keys that joined before are not counted, so a restarted room fills up again without tripping it.
  • A player who solves a captcha once gets a proof tied to their browser's key and skips captchas in every room for 30 days. Raiders who make a new key for each join solve one every time.
  • Opening a room needs a captcha once: from the Create Room button, or for a script through a token from /headlesstoken. A room that comes back with its roomSecret needs none.
  • Golix's operators can ban an identity from every room at once; it is turned away at the join and removed from rooms it is in. Bans from kickPlayer stay with the room.

The captcha is Cloudflare Turnstile. setRequireRecaptcha(true) turns it on for good; on a lobby without Turnstile keys it and the raid guard allow one join attempt per address every 30 seconds instead.
